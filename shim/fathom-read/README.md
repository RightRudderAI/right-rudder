# fathom-read is now right-rudder

Fathom is now Right Rudder, by Embedded Risk Analytics. This final release of `fathom-read` installs `right-rudder` and keeps `import fathom_read` working with a deprecation warning. New code should install and import the new name.

```
pip install right-rudder
right-rudder demo
```

The reads and the hosted service stay as they were, and existing free keys keep working. Source and documentation live at [github.com/RightRudderAI/right-rudder](https://github.com/RightRudderAI/right-rudder).
